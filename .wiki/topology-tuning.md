# Claude topology to finite tuning

`lab.topology_run` admits a separately reviewed finite menu around one exact
validated Claude revision. It leaves the original seed8 campaigns frozen.
`lab.topology_tuning` pins every simulator Python source file, the parent SHA,
the complete legal parameter menu, exact unique replacement anchors and the
default assignment. Defaults must reproduce the parent byte for byte. This is
a coordinator-authored manifest containing source transformations, never an
instruction to execute arbitrary model output.

The runner imports a full official-and-strict passing parent result. A single
full result permits exploration; it does not establish a repeat-confirmed gain.
Training requires the rendered complete source map and the full evaluation
cohort to match. Exact job IDs and SHAs remain attached even when identical
sources have multiple measurements. Screen timings, infrastructure failures and
other topologies never train the surrogate. Scientific full failures receive
the explicit fixed infeasibility penalty, and cannot be proposed again.

The first four distinct full observations are collected through deterministic
Hamming-neighborhood startup. Subsequently SMAC3 2.4.1 fits its random forest and
scores only legal unseen assignments with expected improvement. Decisions label
startup versus actual trained acquisition, including ranks and scores. There
is no random fallback. Conditional constraints are represented by the explicit
legal menu; the maximizer never evaluates excluded combinations. Each rebuild
has fixed seed zero, 32 trees, one worker and no simulation target function.

Use an isolated Python 3.12 environment with `ops/smac/requirements.lock`, setting
`OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1`. The controller runs
on the Mac; the existing trusted client submits exact commits to the unchanged
serial AMD queue. No AMD or shared dependency changes are needed.

```
python -m lab.topology_run init --name topology-smac-v1 \
  --state /absolute/path/.lab/campaigns/topology-smac-v1 \
  --manifest /absolute/path/manifest.json \
  --seed-report /absolute/path/seed-full.json \
  --max-evaluations 10 --deadline-unix AUTHORIZED_ABSOLUTE_DEADLINE --publish
python -m lab.topology_run run --state /absolute/path/.lab/campaigns/topology-smac-v1
```

The Campaign ledger owns reservations, persistent request IDs, budget admission,
full evidence, and exports for the existing dashboard. The runner persists a
selection before committing. Recovery recognizes one exact source commit and
reuses the pending candidate and evaluator requests; dirty partial writes stop
for operator review. A controller lock prevents a second owner. A STOP file
drains already selected work; deadlines still prevent new evaluation admission.
No timer or restart extends the frozen deadline. Preserve all trials and finish
with paired confirmation before promoting a noisy timing difference.
