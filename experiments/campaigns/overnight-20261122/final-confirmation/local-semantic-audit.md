## Mechanisms and integrity

- Lazy Plotly import returns the original visualization function on demand. Plot rendering is outside the simulation task; physics code remains imported normally. Local import of `jax.scipy.linalg` is confined to the dense branch that actually uses it. Public fallback branches remain present.
- Package compiler defaults remain optimization level zero and disabled CPU fusion emitters; no fast-math, reduced precision, hidden persistent compilation cache or extra-thread setting was added. Effective flags must still be recorded by the evaluator.
- Sparse structure includes base nonzeros **and every writable/connector coordinate**, so zeros at initial parameter values are not automatically discarded. Structural gathers use unique in-bounds coordinates generated from the matrices. Changed index snapshots are copied and read-only, rather than aliased to mutable caller arrays.
- The static parameter fast path is conditional on supported layouts and unique bounded destinations; unsupported layouts retain generic indexing. Identity-link elimination verifies actual registered function identity and identical source/destination indices. Empty detector-phase scatter elimination is based on an empty structural placement array, not a numerical value. Neither predicate names a benchmark or recognizes expected answers.
- Builder changes schedule every member of a grouped optimization input and every carrier component directly reading an optimized/swept index. This broadens dependency coverage, including initially zero contributions. Named identity registration uses its actual registry slot, avoiding accidental use of another setup's real linking function. These are semantic corrections, not merely timing changes; passing existing setups does not prove every possible linking topology.
- `SystemPlan` preserves final-write semantics, and its hash now includes derivative-slot group lengths so different group partitions cannot share a key merely because their flattened slots match. Skipping an unused primal output in `function_jacobian(..., with_outputs=False)` does not skip the derivative calculation.
- The host component implementation reuses component-function source with NumPy primitives and Wirtinger duals. Complex conjugation is handled explicitly rather than assuming all components are holomorphic.
- The `_ASSEMBLY` object is a single-use forward/backward residual store. Every forward call assembles again and replaces it. Backward consumes a key binding the static plan and all numeric assembly inputs, then clears it; a miss recomputes. Cached factors are forward residuals for the corresponding reverse pass. There is no lookup that skips a subsequent forward evaluation or supplies fixture answers. Topology-only matvec/transpose caches likewise store coordinate metadata, not physical results.
- Forward and reverse solves retain complex128/float64, iterative refinement and explicit complex transpose conventions. Carrier, signal and noise outputs and reverse sensitivities remain computed. No frequency/variable sampling was introduced.

## Remaining caveats, mostly already in the incumbent

1. The optimized whole-host path is a first-order reverse-mode interface. Higher derivatives/JVP support is not universal; documented generic alternatives exist. That is narrower than claiming complete substitutability for every JAX transformation.
2. Hermitian/collinear adjoint shortcuts use an approximately eight-machine-epsilon residual guard. The identities are exact under their mathematical hypotheses, but floating-point proximity alone is not a proof under arbitrary ill-conditioning. These guards were already in the incumbent, not introduced by the final f856 changes. Preserve existing numerical caveats and the pristine-reference disagreement records.
3. Direct loading of SciPy's private SuperLU extension is version-dependent. Loader failures fall back to the public solver, but the source's broad “any failure” wording overstates this: a later `gstrf` invocation failure is not caught by the loader fallback. This is an inherited portability risk in the fixed tested environment, not evidence of altered answers.
4. Static plans require rebuilding when index topology/selectors change. Owned snapshots prevent accidental mutation but do not make arbitrary post-build index changes supported. New dependency scheduling follows direct optimized/swept indices; it is not a formal proof covering arbitrary custom linking graphs, overlapping writes or invalid inputs.
5. The 14-case suite and both public benchmarks establish tested-domain evidence only. They cannot prove correctness for every optical setup. No tests were added to or rerun outside the authorized evaluator during this inspection.
